## Challenges & Recurring Patterns

1. **Non-atomic check-then-write (TOCTOU) is now a family, not an incident.** Create (2.3), update (2.4), and concurrent category-reassign (2.6) all defer the same race: check then write with no wrapping transaction/lock. Individually fine under the single-operator local runtime — but the same deferral four times is a batch of latent bugs if the deployment model ever gains concurrency.
2. **Cross-package duplication keeps getting deferred.** `POSITIVE_AMOUNT_PATTERN` / `CALENDAR_DATE_PATTERN` are byte-identical API-side and frontend-side (flagged 2.3, still open). The redirect page-math approximation was inherited verbatim create → edit → delete (2.3→2.4→2.5).
3. **The `@supertool/shared` dist-consumption gotcha bit three stories.** 2.2/2.3/2.4 each rediscovered that regenerating the client isn't enough — `@supertool/shared` must be rebuilt (app consumes it from `dist/`). Now in memory.

## 🚨 Significant Discovery — Epic update required: MINOR–MODERATE

**1. Currency model contradicts Epic 3's FRs (decided this retro).** Currency was simplified product-wide to one onboarding default per user (2.5 decision; memory `currency-simplified-single-default`), and the seed is UAH-only — but Epic 3 as written assumes a live currency picker (FR14 data-derived options + profile default + most-frequent fallback; 3.1 "selecting one re-scopes all dashboard figures — no cross-currency aggregation"; 3.2/3.3 honor a currency selection).
   - **Decision (Oleksii, 2026-06-15): Drop the currency filter; keep per-currency correctness.** No currency-picker UI. The dashboard scopes to the profile default currency; aggregations stay per-currency in SQL so correctness is preserved if multi-currency data ever appears. **Reconcile FR13–FR16 + the 3.1/3.2/3.3 ACs to match before drafting Epic 3 stories** (a `correct-course` / PRD-addendum sync).

**2. Docker `api` image build is broken (2.1 regression, still open).** `emit-openapi.js` runs `parseEnv()` at build time and requires `SEED_OPERATOR_PASSWORD`, which `docker/api.Dockerfile` doesn't supply — so `compose:up --build` fails and every Epic 2 visual QA fell back to dev servers (memory `docker-api-build-needs-seed-operator-password`). Dents the one-command-runtime promise.
   - **Decision (Oleksii, 2026-06-15): Fix as Epic 3 prep, before 3.1.** Stub/skip auth-env at OpenAPI emission so `compose:up --build` works and Epic 3 visual QA can run against the real container.

**3. Minor doc drift.** PRD/epics still describe the seed as flat `{Date, Category, Type, Amount}`; reality is two-level with `Subcategory` on 57% of rows (memory `seed-data-has-subcategory`). Fold into the same PRD-addendum sync.

**Positives carried into Epic 3:** the D1 decimal-safe harness was purpose-built for the analytics stories; the recursive-CTE category subtree resolution (2.5) directly serves FR15's parent roll-up. The `analytics` module starts on solid ground.
