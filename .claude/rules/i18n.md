# i18n Conventions

- Messages are split per namespace: one file per feature/page in `apps/<app>/messages/{en,uk}/<namespace-file>.json` (e.g. `navigation.json`, `home-page.json`) — never a single `en.json`/`uk.json` per locale. Reference: `example/track-my-life/apps/money-tracker/messages/`.
- Namespaces are registered in `src/i18n/constants/i18n-namespace.ts` (`I18N_NAMESPACE` as-const + `I18Namespace` union) and mapped to file names in `localization-messages-file-name-by-namespace.ts`; `getMessagesByLocale` (`src/i18n/utils/`) loads and deep-merges them with EN fallback.
- Every key lands in BOTH locales in the same commit — `pnpm i18n:parity` gates missing/extra keys and files (EN is the reference locale).
- Keys: nested camelCase, ICU interpolation only — no string concatenation for sentences.
- Component usage: `const translate = useTranslations('<namespace>')` (the repo-wide `id-length` lint rule rejects `t`).
- Real Ukrainian translations, not transliterated English.
